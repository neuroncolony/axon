## API contract (all under /api/, use AXON.api)
- GET tokens?sort=&model=&status=&limit= -> {tokens:[record]}. record: token, curve, name, symbol, model, modelName, logo ('' or url), logoUrl (always set, '/api/token/0x…/logo', serves real logo or generated SVG), priceEth, priceUsd, marketCapEth, marketCapUsd, volume24hUsd, volume24hEth, trades24h, graduation (0..1 or null), status ('Curve'|'Graduated'), launchedAt, deployer, description, curveState {graduated (bool), ethReserve, tokenReserve, graduationThreshold, balanceWei (str wei), priceEth}, lastTradeAt.
- GET token/<addr> -> record + events[], takes[], bets[], spentUsd.
- GET trades?token=<addr>&limit=100 -> {trades:[{side:'buy'|'sell', trader, ethWei, tokenWei, priceEth, tx, block, at}]} newest first; without token also token + symbol per item.
- GET candles?token=<addr>&interval=300&limit=200 -> {candles:[{t,o,h,l,c,vEth}], priceEth, ethUsd}. Offer intervals 60, 300, 900, 3600, 86400.
- GET live?limit=60 -> {events:[{type:'launch'|'buy'|'sell'|'take'|..., token, symbol, model, by, ethWei?, tokenWei?, tx, at}]}.
- quote / trade/prepare exist already; keep the trade widget logic in token.html. Change the sentence 'Price is a spot quote for a 0.001 ETH buy...' to 'Price is the spot price from the curve reserves, read live. Volume and trades are read from the chain.'
